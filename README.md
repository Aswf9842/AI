# 🗣️ HumanSpeak · 人话转换器

> 把任何天书变成大白话 · 高情绪治愈工具  
> Turn jargon into human talk · High-vibe learning tool

## 这是什么 / What is this?

一个纯前端工具，输入任何晦涩难懂的知识点，一键生成"大白话"版本。

A frontend-only tool. Input any complex concept, get a plain-language explanation instantly.

### 核心特性 / Features

- 🌍 **5种语言界面**：中文 / English / Español / 日本語 / العربية
- 🎨 **5种解释风格**：极简大白话、比喻狂魔、故事大王、幽默脱口秀、类比专家
- 🥚 **彩蛋系统**：隐藏小惊喜等着你发现
- 🚫 **零后端**：纯 HTML / CSS / JS，部署到 GitHub Pages 即可
- 🔒 **零隐私风险**：不收集任何数据，不需要 API Key

### 支持的知识领域 / Supported Topics

已内置以下领域的大白话翻译示例：

- 量子物理（量子纠缠、黑洞）
- 计算机科学（递归、过拟合、DNS、区块链）
- 经济学（机会成本、边际效用递减）
- 数学/统计（贝叶斯定理、幸存者偏差）
- 经典物理（牛顿定律）
- 热力学（熵）

## 🚀 部署 / Deploy

```bash
# 1. 下载本仓库
git clone https://github.com/<你的用户名>/humanspeak.git

# 2. 直接上传 index.html 到 GitHub 仓库根目录
# 3. 仓库 Settings → Pages → 选 main 分支 → Save
# 4. 等2分钟，你的站点就上线了
```

也可以直接双击 `index.html` 在本地打开。
